## How It Works (Onboarding in days, not months)
1. **Set up your workspace** — import employee records, contracts & leave balances via guided onboarding + templates
2. **Automate day-to-day HR** — staff self-clock-in, request leave, update details; approvals auto-routed
3. **Run payroll with confidence** — review hours/leave/bonuses, run PAYE-compliant payroll, submit RTI to HMRC
4. **Track performance & growth** — set goals, run review cycles, gather feedback
